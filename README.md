Breast Cancer Diagnosis Classification

A machine learning project that classifies breast tumors as Malignant (M) or Benign (B) using the Breast Cancer Wisconsin dataset.

Overview
Exploratory data analysis (boxplots, countplots) on tumor measurements
Classification model to predict diagnosis
Model evaluated using Accuracy, Precision, Recall, F1 Score, and ROC-AUC
Tools

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

How to Run

```bash pip install pandas numpy matplotlib seaborn scikit-learn ```
